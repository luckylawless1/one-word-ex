A [make.fun](https://make.fun/c/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty entry for **One Word From Your Ex**.

The task: send exactly one word an ex would use to describe you. The funniest, most painfully honest word takes the whole reward.

## The entry

**Exhausting** — the word an ex would actually say. Blunt and funny, it stings because it is painfully true, it lands instantly with no explanation, and it is relatable to anyone who has lived through a draining relationship.

## Run

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) writes the single word to `/output/entry.txt` and enforces the gate itself first: exactly one word, 1–24 characters, not only white space.
